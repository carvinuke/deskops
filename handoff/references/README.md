# Visual references

Four **original SVG mockups** are packaged locally:

- `mock-dashboard.svg` and `mock-dashboard.png`
- `mock-ticket-detail.svg` and `mock-ticket-detail.png`
- `mock-tools-menu.svg` and `mock-tools-menu.png`
- `mock-server-room.svg` and `mock-server-room.png`

Open the SVGs in a browser or use the PNG previews. They are schematic redraws created for this handoff, not screenshots of the original product.

Open `reference-gallery.html` to compare these mockups with nine public screenshot links from the reference site. The linked images are displayed from their source URLs, so those image slots require internet access. The game itself must not use those URLs or depend on them.
