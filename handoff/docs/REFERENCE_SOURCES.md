# Reference Sources & Visual Study Notes

These sources document the public ServiceDesk Simulator interface and help explain how its screens behave. Use them as **research references only**. Do not package these screenshots into the final playable game, copy its logo/branding, or lift the site's exact text. The mockups stored beside this file are original schematic redraws made for the DeskOps Lab brief.

## Direct screenshot links

1. **Incident queue rows** — [ticket-queue.png](https://servicedesk-simulator.com/learn/ticket-queue.png)  
   Study: compact row height, requester under title, priority word aligned right, quiet dividers and no oversized cards.

2. **Open ticket header** — [ticket-open-header.png](https://servicedesk-simulator.com/learn/ticket-open-header.png)  
   Study: ID and priority above a prominent ticket title; assignment state and assign-to-me action directly underneath; options menu at the far right.

3. **Tools drawer/menu** — [tools-menu.png](https://servicedesk-simulator.com/learn/tools-menu.png)  
   Study: categories divided by hairline rules, icons in a consistent left column, group headings in spaced uppercase, console labels easy to scan.

4. **Directory console** — [directory-panel.png](https://servicedesk-simulator.com/learn/directory-panel.png)  
   Study: user list on the left, management tabs in a narrow center rail, selected user and actions in the main pane. Actions should be compact and state-aware.

5. **Server Room overview** — [server-room-overview.png](https://servicedesk-simulator.com/learn/server-room-overview.png)  
   Study: status summary cards on top, device table left, CPU/memory meters right, blue accent for healthy system telemetry.

6. **Server topology** — [server-room-topology.png](https://servicedesk-simulator.com/learn/server-room-topology.png)  
   Study: network hierarchy from Internet/ISP down through router/firewall, then grouped zones. Make the diagram functional and clickable, not just decorative.

7. **Remote desktop connection list (illustration)** — [illus-remote-support.png](https://servicedesk-simulator.com/learn/illus-remote-support.png)  
   Study: dense device inventory table with hostname, group, status, last session and action column.

8. **Remote login dialog** — [remote-login.png](https://servicedesk-simulator.com/learn/remote-login.png)  
   Study: focused machine identity, credential context, visible hint affordance. For DeskOps, use only fictional simulated credentials and make clear it is a lab.

9. **Simulated desktop** — [remote-desktop.png](https://servicedesk-simulator.com/learn/remote-desktop.png)  
   Study: top connection strip, app icons, wallpaper, taskbar and disconnect control. Use original artwork in the game.

## What to copy as a *pattern*, not as exact artwork

- A compact incident queue with title, requester and priority.
- A full ticket record with a visible assignment control.
- A top-bar tools menu organized around actual IT department responsibilities.
- Admin consoles built from dense tables, detail panes, status badges and short actions.
- Correct diagnosis relies on finding the right source of truth, not guessing.
- Realistic admin tasks produce state changes that affect other screens.

## Suggested original differentiators

- DeskOps Lab name and custom two-window glyph.
- Northstar Office Group fictional domain and seeded data.
- Original SVG icons / topology / desktop wallpaper.
- Slightly more legible modern spacing where a screenshot is unusually small.
- No login, subscriptions, leaderboard server, class mode or web-only features. All progress is local to the player's browser.
